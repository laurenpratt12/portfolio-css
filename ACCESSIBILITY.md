# Accessibility Audit

## Overview

I used Google PageSpeed Insights to check the accessibility of my portfolio website and identify areas that could be improved.

My initial accessibility score was **95**.

## Issues Found

The initial audit identified a color contrast issue. Some of the text on my website did not have enough contrast against its background, making it harder to read.

The issue was found with the technology labels in the Skills and Projects sections.

## Changes Made

To improve the readability of my website, I made the following changes in my `style.css` file:

- **Lightened the text color** so the text is easier to see.
- **Darkened the background color** behind the text to create better contrast.
- Updated the colors used for the skill labels and project technology labels.

These changes help make the text easier to read and improve the overall accessibility of the website.

## Accessibility Testing

I used Google PageSpeed Insights to identify the original contrast issue. After making the CSS changes, I will run the accessibility audit again to check whether the issue has been resolved.

I will also test my website using keyboard navigation to make sure links and other interactive elements can be accessed.

## Final Results

- Initial accessibility score: **95**
- Final accessibility score: **100**
- Main improvement: Better color contrast and text readability.

## Conclusion

This audit helped me identify an accessibility issue on my portfolio website and make changes to improve the experience for visitors. Improving the contrast between text and backgrounds makes the website easier to read and more accessible.

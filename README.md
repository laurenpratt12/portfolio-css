# Lauren Pratt — Personal Portfolio

## Overview

This is my personal portfolio website, created to introduce myself as a Computer Science student at Michigan State University and showcase my programming skills and projects. The website includes information about my background, education, technical skills, projects, and contact information.

## Features

* **About Me:** An introduction to my background and interests in computer science, web development, and software engineering.
* **Education:** Information about my studies at Michigan State University.
* **Skills:** A list of programming languages and web development technologies I have worked with.
* **Projects:** A collection of projects I have created, including interactive websites, chatbots, and web applications.
* **Contact:** Links to my LinkedIn, GitHub, and email.

## Technologies Used

* HTML5
* CSS3
* Google Fonts
* Responsive design techniques

## Design

The portfolio uses a personalized color palette featuring peach (`#ECBEB4`), blush pink (`#EABFCB`), muted purple (`#726E97`), dusty blue (`#7698B3`), and light blue (`#83B5D1`).

The design includes rounded corners, subtle shadows, hover effects, and custom fonts to create a modern and consistent look. Space Grotesk is used for headings, Inter for body text, and JetBrains Mono for technology labels.

The layout uses CSS styling without Flexbox or CSS Grid.

## Featured Projects
